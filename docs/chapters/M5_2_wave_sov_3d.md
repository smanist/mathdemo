# String Vibration by Separation of Variables (3D)

This standalone demo migrates the source notebook
`M5_2_wave_sov_3d.ipynb`. It uses the same fixed-end string problem as the 2D
separation-of-variables view, but plots the solution over the space-time plane
as surfaces.

The top surface shows the d'Alembert solution. The lower surfaces show the
first two modal contributions.
