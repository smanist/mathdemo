# Fourier Series of Extended Functions

Consider the function

```{math}
f(x) =
\begin{cases}
\pi - x, & 0 \le x \le \pi, \\
0, & \text{otherwise}.
\end{cases}
```

The original notebook compared three ways to extend the data from `[0, \pi]`
to `[-\pi, \pi]` before forming a Fourier series: a simple extension, an even
extension, and an odd extension.
